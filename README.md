# Rally Lens

Tennis video analyzer that runs entirely in the browser: ball speed, spin and bounce,
in/out calls, volleys, player tracking for singles and doubles, automatic scoring and
match stats, coach's notes, highlight reels and 3D shot replays.

Open the live site, upload a rally filmed from behind the baseline, mark the four court
corners and press Analyze. Videos never leave your device. On a phone, use
"Install app" / "Add to Home Screen" to install it and use it offline.
